# Product icons

Generated by `tauri icon` from `source.png` (1024×1024 RGBA, the
canonical master). The mark is a bold "M" with a diagonal accent-purple
strikethrough — same motif as the `delete-me` brand mark in the Tauri
UI nav (`tauri-app/ui/src/routes/+layout.svelte`).

## Regenerating

If you change the source, re-run from `tauri-app/src-tauri/`:

```bash
# Regenerate source.png from the brand definition
uv run python ../../scripts/gen-icon.py

# Fan out to every platform format
pnpm dlx @tauri-apps/cli@latest icon icons/source.png
```

Files this produces:

- `icon.icns` — real multi-resolution macOS icon
- `icon.ico` — real multi-resolution Windows icon
- `icon.png`, `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png`
  — Linux + general-purpose
- `android/` and `ios/` — mobile launcher assets (forward-compatible
  with `tauri android`/`ios` if/when those targets are wired up)
- `Square*Logo.png`, `StoreLogo.png` — Microsoft Store assets

`source.png` is checked in so the icon mark survives without needing
the generator script in a fresh clone; the script is checked in too so
the design can be tweaked deterministically.
