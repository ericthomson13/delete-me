# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org)
version 2.1. The canonical text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html.

Summary:

- Be kind. Assume good faith. Disagree without being a jerk.
- Harassment, discrimination, and personal attacks are not tolerated.
- Maintainers will enforce this code; report incidents via
  **eric.thomson13@gmail.com** with `[delete-me coc]` in the subject.

The full text governs.
